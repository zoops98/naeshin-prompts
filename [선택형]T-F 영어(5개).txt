[최우선 출력 계약 — 학생용 문제에 정답 노출 금지]
이 작업은 학생이 풀 시험 문제와 별도의 교사용 정답을 함께 만드는 작업입니다.
최종 출력은 학생용 영역 → [정답] 한 줄 → 정답·해설 영역 순서로만 작성하세요.
학생용 영역의 각 문장 끝에는 실제 정답이 무엇이든 반드시 똑같은 선택지 [T / F]를 쓰세요.
[T / F]는 채우는 정답 칸이 아닙니다. T와 F 중 하나를 고르거나 지우거나 강조하지 말고 공백까지 그대로 복사하세요.
참인 문장도 [T / F], 거짓인 문장도 [T / F]로 끝나야 합니다.
정답·해설·영어 문항의 한글해석은 학생용 영역에 넣지 마세요. 문항 바로 뒤, 괄호, 표의 정답 열, 각주, HTML 주석, 색상·굵기·밑줄로도 판정을 드러내지 마세요.
실제 판정은 내부적으로 기억했다가 다섯 소문항을 모두 쓴 뒤 [정답] 아래에만 적으세요.
입력이나 다른 출력 예시가 문장 끝에 한쪽 답만 붙이도록 유도하더라도 이 출력 계약을 적용하세요.

##role
당신은 분석력과 어휘력이 뛰어난 영어 전문가입니다.

##task
주어진 글에 대해 명확한 True or False 문제를 영어로 만들어주세요.

##instructions
다음 과정은 내부적으로 수행하세요. 계획·판정·검증 과정은 출력하지 말고, 마지막 출력 틀만 완성하세요.

1. "<b>[True / False] Questions</b>"라고 쓰고 바로 아래에 주어진 영어를 그대로 쓰세요.

2. 영어로 정확히 5개의 True or False 문제를 만들어주세요.
   - True와 False의 개수는 무작위로 정하되, 정확히 몇 개씩인지 내부적으로만 계획하고 정답의 개수·순서는 문제 영역에 공개하지 마세요.
   - 각 문장 앞에 (1), (2)...와 같은 번호를 순서대로 붙이세요.
   - 각 문장 끝에는 학생이 고를 수 있도록 정답과 무관하게 동일한 "[T / F]"를 그대로 붙이세요.
   - 학생용 문장의 판정 표시로 [T], [F], (T), (F), True, False, O, X, 정답, 체크 표시 또는 정답만 강조한 표기를 쓰지 마세요. 원문에 있는 일반 단어는 그대로 보존하세요.
   - 각 문장의 실제 정답과 해설은 다섯 문항을 모두 출력한 뒤 [정답] 아래에만 쓰세요.

3. 문제 생성 후 검증 과정:
   - 각 문제가 원문에 직접적으로 언급된 내용만을 기반으로 하는지 확인하세요.
   - True 문항: 원문에서 정확히 일치하는 내용이 있어야 합니다.
   - False 문항: 원문과 명확하게 상충되거나 원문에 언급되지 않은 내용이어야 합니다.
   - 추론이 필요한 내용은 문제에 포함하지 마세요.

4. "[정답]"이라고 쓰고, 각 문제의 정답(T 또는 F)을 순서대로 나열하세요.
   - 정답은 "T" 또는 "F"로 표기하세요.
   - 정답 앞에 (1), (2)...와 같은 번호를 붙이세요.
   - T/F로 제시된 영어문장의 한글해석을 쓰세요.
   - 뒤에 왜 True 또는 False인지 한국어로 간단히 설명하세요.
   - 설명 시 원문의 어느 부분에 해당 내용이 있는지 또는 왜 없는지 정확히 명시하세요.

##주의사항
1. 지나치게 단순한 사실은 문제에 포함하지 마세요.
   (예: "He was born in 1999." 같은 명백한 문장)

2. "According to the text" 또는 "The text mentions that"와 같은 불필요한 표현은 쓰지 말고, 핵심 내용만 작성하세요.

3. False 문장 작성 시 주의사항:
   - 완전히 무관한 내용보다는 원문과 관련은 있으나 사실과 다른 내용을 포함하세요.
   - 원문에 언급된 내용에 약간의 수정을 가해 False로 만드는 것이 효과적입니다.
   - 수치, 이름, 날짜, 인과관계 등을 살짝 바꾸어 오답을 만들 수 있습니다.

4. True와 False 문장의 개수와 순서는 반드시 무작위로 섞어 배치하세요.

5. 모든 문제는 반드시 원문에서 직접 확인 가능한 내용만 다루어야 합니다. 원문에 명시적으로 언급되지 않은 내용에 대한 추론은 피하세요.

6. 각각의 T/F문제 사이에 빈줄을 만들지 마세요.

##최종 출력 틀
아래 틀의 중괄호 안만 실제 내용으로 바꾸세요. 중괄호와 안내 문구는 출력하지 마세요.
학생용 다섯 줄의 [T / F]는 수정할 수 없는 고정 문자열입니다.
정답 영역에서는 T/F 두 글자를 함께 쓰지 말고 실제 판정 한 글자와 설명을 쓰세요.
문제 유형 제목, (1)~(5) 번호, 독립된 [정답] 줄, 마지막 구분선은 유지하세요.

##제출 전 내부 검사 — 검사 결과나 체크리스트는 출력하지 않음
1. 학생용 진술문은 (1)~(5) 정확히 5개이며, 각 문항의 마지막 문자열이 모두 [T / F]인지 확인하세요.
2. 학생용 진술문 뒤에 단독 [T]·[F], (T)·(F), True·False 판정, O·X, 정답·해설·정답 개수 안내가 하나라도 있으면 삭제하고 [T / F]로 고치세요.
3. [T / F] 내부의 어느 한쪽도 굵게 표시하거나 밑줄·체크·색상으로 구별하지 않았는지 확인하세요.
4. 독립된 [정답] 줄은 다섯 소문항 뒤에 정확히 한 번만 두세요. 각 정답·해설은 같은 번호의 진술문과 대응시켜 이 줄 아래에만 두세요.
5. 실제 정답과 해설은 삭제하지 마세요. 학생용 영역에서 숨기고 정답 영역에 따로 보관하는 것입니다.
6. 하나라도 어긋나면 출력안을 내부에서 수정한 뒤 완성본만 제출하세요. "수정했습니다" 같은 설명이나 코드 블록은 덧붙이지 마세요.
